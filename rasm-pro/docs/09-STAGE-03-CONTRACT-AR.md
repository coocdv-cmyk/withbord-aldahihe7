## 2. القرارات المعتمدة

| القرار | الاختيار | السبب |
|---|---|---|
| مفتاح الأصل | `a-<sha256[:12]>` | يعرّف **البصمات** لا المسار؛ ينجو من نقل المشروع |
| سجل القرارات | `research/approvals.jsonl` (append-only) | لا يُعاد كتابة التاريخ؛ المانيفست مجرد إسقاط |
| وضع الرندر الافتراضي | `final` (يمنع غير المعتمد) | «الإنتاج» يعني إنتاجًا، لا معاينة |
| وضع المعاينة | `--preview` (أو `--max-seconds`) | يسمح بالتحقق البصري مع تحذير صريح |
| أصل مرفوض | يمنع في **كل** الأوضاع | الرفض قرار نهائي |
| أصل بلا ترخيص/مصدر | يمنع في الإنتاج، تحذير في المعاينة | لا نشر بلا أساس قانوني |
| صورة مولَّدة كدليل | يمنع في كل الأوضاع | المولَّد ليس دليلًا تاريخيًا |
| Studio | `mode='preview'` افتراضيًا | الاستوديو معاينة تفاعلية؛ الإنتاج يحتاج `mode='final'` |
| روابط الأصول في الخطة | نسبية + `asset_id` | قابلية نقل، وإزالة المسارات المطلقة |

## 4. العقد

### 4.1 هوية الأصل

- `asset_id = "a-" + sha256[:12]` — ثابتة عبر نقل المشروع.
- المانيفست سجل الأصول؛ الخطة تشير بـ `asset_id` (والمسار النسبي).
- المسار المطلق داخل المشروع يُطبَّع إلى نسبي في `plan link-assets` (مع نسخة قبل الكتابة).

### 4.2 سجل الاعتماد

- كل قرار سطر JSONL في `research/approvals.jsonl`:
  `asset_id, path, decision, reviewer, reviewed_at, note, license, source, origin_url`.
- القرارات: `approved` / `rejected` / `deferred`.
- **لا بد من اسم مراجع**، ولا قرار غير معروف.
- سجل تالف = خطأ صريح (لا تجاهل).
- المانيفست يحمل `approval{decision, reviewer, reviewed_at, note, records}` +
  `approval_log{path, records, sha256}`.

### 4.3 البوابة

| الحالة | `final` | `preview` |
|---|---|---|
| أصل غير معتمد (`pending`/`deferred`) | ⛔ يمنع | ⚠️ تحذير |
| أصل مرفوض | ⛔ يمنع | ⛔ يمنع |
| بلا ترخيص | ⛔ يمنع | ⚠️ تحذير |
| بلا مصدر (origin) | ⛔ يمنع | ⚠️ تحذير || غير مسجّل في المانيفست | ⛔ يمنع | ⚠️ تحذير |
| ملف الأصل مفقود | ⛔ يمنع | ⛔ يمنع |
| مولَّد يُستخدم كدليل | ⛔ يمنع | ⛔ يمنع |
| أصل **غير مستخدم** في الخطة | لا تأثير | لا تأثير |

- الرندر **لا يبدأ** إذا كانت البوابة مغلقة، و**لا يُنشأ ملف إخراج**.
- الرسالة تذكر كل أصل مع الأسباب، وكيف تعتمد أو كيف تعاين.

### 4.4 دمج البحث

`rasm approvals import <project>`:
- يقرأ `research/assets.json` → مدخلات المانيفست (مصدر + ترخيص + إسناد + هاش).
- يحافظ على حالة الاعتماد الموجودة، ويبدأ الجديد `pending`.
- `dry-run` متاح، والعملية idempotent.

## 5. الأوامر

```powershell
rasm approvals list ww1                 # كل الأصول وحالة الاعتماد
rasm approvals list ww1 --used-only     # المستخدمة في الخطة فقط
rasm approvals approve ww1 --asset a-c75888b731eb --by "اسم المراجع" --note "..."
rasm approvals reject  ww1 --asset assets/event-.../x.jpg --by "اسم المراجع"
rasm approvals defer  ww1 --asset <path> --by "اسم المراجع"
rasm approvals sync   ww1               # إسقاط السجل على المانيفست
rasm approvals import ww1               # دمج أصول البحث
rasm approvals gate   ww1               # فحص البوابة (final/preview)
rasm project link-assets ww1            # ربط الخطة بالأصول (نسخة قبل الكتابة)
rasm render ww1                        # إنتاج: يُمنع إن كان هناك أصل غير معتمد
rasm render ww1 --preview              # معاينة: تحذير بدل المنع
```
