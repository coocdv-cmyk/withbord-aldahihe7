## 0. لماذا هذا العمل

كان `config.json` يعلن `tts.backend: none | edge | azure | elevenlabs | local`
ولم يكن هناك **أي تنفيذ** لأحدها. النتيجة: «حلقة بلا سرد» كانت نتيجة **بنية**
لا خيارًا، و`G2` في تدقيق الجاهزية كان بلا طريق تسدّه.

واختيار المالك كان واضحًا: **نفّذ TTS داخل المحرك**. هذا الملف يوثّق التنفيذ
والنتيجة المقيسة.

## 1. ما بُني

### 1.1 `rasm-pro/engine/audio/tts.py` (جديد)

| العنصر | السلوك |
|---|---|
| `TtsConfig` | من `config.tts` + `RASM_TTS_*` (backend/voice/rate/pitch/sample_rate) + مفتاح/منطقة Azure |
| المزوّدات | `edge` (حزمة `edge-tts` اختيارية) · `azure` (Neural TTS بـ SSML) · `none` (يرفض) |
| `split_script` | فقرة = مشهد (سطر فارغ أو `---`) |
| `assemble_narration` | لصق مشاهد WAV بصمتات **مقيسة بالعينات** بين المشاهد فقط (لا صمت بعد آخر مشهد) + lead-in **قبل** أول كلمة |
| `synthesize_narration` | توليد مشهد مشهد ثم تجميع — مع **حقن المُولِّد** (اختبار بلا شبكة) |
| `synthesize_project` | يولّد داخل المشروع ثم **يستورد** عبر `import_narration` مع تسجيل **أصلية** التوليد |

**الانضباط:**
- **مزوّد واحد معلن** — لا انزلاق صامت إلى مزوّد آخر.
- كل عطل **خطأ صريح**: حزمة ناقصة / مفتاح ناقص / انقطاع شبكة ⇒ `TtsError` بنصيحة التثبيت.
- الناتج **ملف سرد عادي**: يمرّ على الاستيراد ⇒ قياس الجهارة ⇒ المحاذاة ⇒ بوابة الصوت.
- `audio/narration.json` يحمل `original.generated_by = "engine.tts"` والمزوّد والصوت والمعدّل.

### 1.2 أمر CLI: `rasm tts`

```powershell
rasm tts <project> [--script FILE] [--backend edge|azure] [--voice V]
                 [--rate=-4%] [--pitch=+0Hz] [--pause 0.8 | 0.5,0.8,...]
                 [--lead-in 0.35] [--lang ar] [--dry-run]
```
> ملاحظة: القيم التي تبدأ بشرطة تُمرَّر بصيغة `--rate=-4%` (قيد argparse).

المسار بعد التوليد هو **نفس** مسار `rasm audio`: محاذاة مقيسة + بوابة صوت.

### 1.3 `\"`اختبارات العقد (13) — `tests/test_tts_contract.py`

`none` يرفض بوضوح · مزوّد مجهول يرفض · حزمة `edge-tts` ناقصة = خطأ صريح ·
Azure بلا مفتاح = خطأ صريح · الصوت الافتراضي حسب اللغة · `RASM_TTS_*` يتغلّب على
الإعدادات · تقسيم السكريبت · الصمتات مقيسة بالعينات والـ lead-in في أوله ·
المشروع بالكامل: توليد ⇒ استيراد ⇒ وصف بأصله · حقن المُولِّد لكل مشهد ·
CLI يرفض بلا مشاهد · CLI dry-run لا يلمس الشبكة.

## 4. كيف تُعاد الحلقة (الأوامر بالترتيب)

```powershell
cd rasm-pro
# 1) سكريبت ← مشاهد (يحترم فقرات الكاتب)
.venv\Scripts\python.exe rasm.py understand projects/episode-01-ar/script.txt --project episode-01-ar --offline
# 2) خطة أولى (عائلة + ميزانية)
.venv\Scripts\python.exe rasm.py plan episode-01-ar --family documentary
# 3) مانيفيست + تفعيل الخطة + استيراد الأصول
.venv\Scripts\python.exe rasm.py project init episode-01-ar
.venv\Scripts\python.exe rasm.py plan episode-01-ar --family documentary
.venv\Scripts\python.exe rasm.py approvals import episode-01-ar
# 4) **توليد السرد داخل المحرك** (يحتاج إنترنت لمزوّد edge)
.venv\Scripts\python.exe rasm.py tts episode-01-ar --backend edge --voice ar-EG-ShakirNeural "--rate=-4%" --pause 0.8
# 5) تطبيع الجهارة إلى الهدف
.venv\Scripts\python.exe rasm.py audio episode-01-ar --normalize -16
# 6) إعادة بناء الخطة بزمن التسجيل **المقيس**
.venv\Scripts\python.exe rasm.py plan episode-01-ar
# 7) ربط الأصول داخل المشروع
.venv\Scripts\python.exe rasm.py project link-assets episode-01-ar
# 8) اعتماد بشري لكل أصل مستعمل (اسم المراجع إلزامي)
.venv\Scripts\python.exe rasm.py approvals approve episode-01-ar --asset a-… --by <name> --note "…"
# 9) اعتمادات + تقرير ميزانية
.venv\Scripts\python.exe rasm.py approvals credits episode-01-ar
.venv\Scripts\python.exe rasm.py plan episode-01-ar --check
# 10) رندر إنتاجي (يرفض قبل الكتابة إن فشل شرط)
.venv\Scripts\python.exe rasm.py render episode-01-ar --out projects/episode-01-ar/render/episode.mp4 --size 1280x720
```

## 5. حدود هذا العمل

1. **السرد مُولَّد بصوت Edge التوليدي** — ليس صوتًا بشريًّا. الهدف: أن يصبح في
   المشروع صوتٌ **يصلح للنشر** يُقاس، لا أن يُنشر كتعليق نهائي.
2. **مزوّد `edge` يحتاج إنترنت**؛ `azure` يحتاج مفتاحًا. لا يوجد TTS محلي بلا
   إنترنت بعد (Kokoro بلا صوت عربي وبلا ربط).
3. **المحاذاة تبقى `SEGMENTED` (0.55)** — لا تفريغ صوتي ⇒ لا توقيت لكل كلمة.
4. **لا «episode-01-en» بعد** — المسار الإنجليزي مُصلَح برمجيًا (doc 04) لكن
   بلا **مقاس** بعد؛ أول حلقة إنجليزية يجب أن تمرّ بنفس الق gates.
5. **الفريق البصري يبقى عمل إنسان** — الفحص آلي (ميزانية النص، الاتجاه، الملاءمة).
6. **الاعتمادات هنا بتوقيع «owner-delegated»** — تفويض صريح من المالك بتاريخ
   2026‑10‑21، لا توقيع مباشر.
