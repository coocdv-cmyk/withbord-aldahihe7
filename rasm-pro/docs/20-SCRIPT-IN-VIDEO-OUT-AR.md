## 1. كيف يعمل الآن (سكريبت → فيديو)

```powershell
cd rasm-pro

# أ) سكريبت جاهز (ملف نصّي عادي — فقرات أو جدار نص)
.venv\Scripts\python.exe rasm.py build my-episode --script script.txt --family documentary
#    ⇒ understand (تقسيم) → research (مصادر مرخّصة) → plan → credits → render (بلا سرد) → sync sheet

# ب) فكرة فقط — الموديل المحلي يكتب المسودّة ثم المحرّك يتحقّق منها
.venv\Scripts\python.exe rasm.py build my-episode --topic "لماذا تنامzl الساعات الجيدة؟" --scenes 10

# ج) листة المزامنة لتسجيلك
.venv\Scripts\python.exe rasm.py captions my-episode
#    ⇒ render/captions.srt + render/sync-sheet.csv

# د) إن أردت سردًا تجريبيًا (TTS) للاستماع فقط
.venv\Scripts\python.exe rasm.py tts my-episode --backend edge --voice ar-EG-ShakirNeural "--rate=-4%"
```

> **بوابة الإنسان لا تُتجاوز**: إن استخدمت الخطة مصادر لم يقرّها أحد، يتوقّف
> البناء ويطبع ما يحتاج قرارًا. مع `--preview` يُنتَج فيديو مسموح به مع تحذير.

## 2. الشخصيات: لماذا هي جزء من العقد لا زينة

الشخصية **متجهية** (parametric): رأس ودقن وجسم وأطراف تتغيّر بالوضعية، وكل
مسار يُرسم بالقلم فيسمع صوت الخدش. والوضعية **تتبع معنى الجملة**:

| في الجملة | الوضعية |
|---|---|
| سؤال (؟ / هل / لماذا) | `think` — تفكير |
| سبب (لأن / لذلك) | `focus` — تركيز |
| فعل (اكتب / اقرأ) | `read` |
| إعجاب/قوة | `like` |
| الختام | `cheer` |
| غير ذلك | `point` |

## 4. حدود صريحة

1. **السرد المُولَّد صوته تركيبي** (Edge) ويحتاج إنترنت؛ الصوت النهائي صوت بشري.
2. **الموديل المحلي 4B** يكتب مسودّة لا تُبنى عليها حقائق: كل ادّعاء يمرّ على
   بوابة البحث والبحث يجد بالاسم (8 من 26 أصلًا في حلقة «فن الحرب» كانت غير
   ذات صلة ورُفضت بالعين) ⇒ **المراجعة البشرية للبحث ما زالت لازمة**.
3. **المحاذاة** `SEGMENTED` (0.55) — لا ASR ⇒ لا توقيت لكل كلمة ولا شفاه.
4. **الاستعادة** تحتاج مساحة (~1GB للحزمة + البيانات) ووسائط خارجية — النسخ
   الفيزيائي **يحتاجك** (لا أستطيع نسخه إلى قرص غير موجود).
5. **الواجهة**: اللوحة الجديدة تعرض الحالة، لكن الواجهة نفسها ما زالت المشروع
   القديم (الـrasm API يعمل، والربط بالواجهة الرئيسية جزئي).
6. **الألوان**: 1.87× للرندر (مقاس على هذه الحلقة) — الرندر الطويل يحتاج وقتًا.
