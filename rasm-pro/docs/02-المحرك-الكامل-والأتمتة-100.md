# 02 — المحرك الكامل + خط الأتمتة 100%
**العقد النهائي: تُلصق السكريبت → يخرج فيديو كامل جاهز للنشر (صوت + صورة + موسيقى + مؤثرات + ترجمة). الخطوة البشرية الوحيدة: تسجيل صوتك إن أردت (ويُزامَن تلقائيًا)، والموافقة على لوحة القصة.**

الإصدار 1.0 · مشروع `rasm-pro`

---

## 0) العقد النهائي بالحرف — ما سيدخل وما سيخرج

```
INPUT
  ├─ السكريبت (عربي أو إنجليزي)                      [إلزامي]
  ├─ ستايل (أرشيف ورقي / Vox / ...)                  [افتراضي تلقائي]
  ├─ الصوت: مولَّد بصوتنا المخصص  ← أو ← تسجيلك الخاص  [اختياري]
  └─ مواصفات: المدة · المقاس · اللغة · مدة المشهد

OUTPUT (كل ما يلي يُنتَج آليًا)
  ├─ video.mp4            1440p/60 · H.264 · -14 LUFS
  ├─ video_vertical.mp4   1080×1920 (شورتس)
  ├─ captions.srt + كابشن محروق داخل الفيديو
  ├─ thumbnail_A/B/C.png  صور مصغّرة بثلاث نسخ للاختبار
  ├─ chapters.txt · العنوان · الوصف · الوسوم (جاهزة للنشر)
  ├─ shorts/*.mp4         مقاطع قصيرة مستخرجة تلقائيًا
  ├─ assets-credits.json  كل أصل + ترخيصه + رابطه
  └─ project.json         المشروع كامل قابل لإعادة الفتح والتعديل
```

**ما لا يفعله الإنسان:** لا بحث، لا تجميع، لا تركيب، لا توقيت، لا مزج صوت، لا تصدير.
**ما يفعله الإنسان:** يلصق السكريبت + يوافق على لوحة القصة + (اختياري) يسجّل صوته.

## 1) المحرك الموروث (VideoScribe 1.21) — تشريح دقيق وما نأخذه منه

### 1.1 كيف يعمل فعليًا (من الكود المُفكوك)
| المرحلة | التنفيذ الحقيقي عندهم | المرجع |
|---|---|---|
| قراءة SVG | تحويل عناصر SVG إلى **مسارات (strokes)** وتحميلها كعناصر PixiJS | `svg-loader.ts` |
| ترتيب الرسم | **ترتيب صفّي (row-major) للجزر** — أي رسم المكوّنات من أعلى لأسفل، وكل جزيرة من اليسار | `playback/helpers/*` |
| الحركة | الرسم عبر `pathLength` + `brushSize` (كشف تدريجي على المسار) | `helpers/*` |
| سماكة الخط | تُحسب من **تكرارات التآكل (thinning)** بعد تصغير النسيج إلى `MAX_TEXTURE_SIZE=500` — Zhang-Suen/Guo-Hall | `scaleTextureForThinning.ts:1-43` · `thinning.ts:5-12` |
| النص | **يُرستَر → يُخفَّف → يتحول لقناع مرسوم** (أي الكتابة مجموعة بكسلات تُكشف) — والعربية بـ`arabic-reshaper` + قلب حروف يدوي | `02` §النص |
| الساعة الوحيدة | **`gsap.ticker`** — لا محرك فيديو إطلاقًا | `03` |
| زمن المشهد | `max(زمن الصوت, زمن العناصر + الانتقال)` + سلوكيات: **دخول / تأكيد (Emphasis) / خروج / وقفة** | `03` |
| تزامن الكلمات | `audioWordforms[assetId] = { state, wordBoundaries: [{text, audioOffsetMs, durationMs}] }` — تزامن محسوب **سيرفريًا** | `01` |
| التصدير | **كله على السيرفر** (`POST /render`)؛ `720MP4_H264` و `420GIF_12FPS`؛ **fps مثبّت 25**؛ لا دقة/بتريت؛ لا مُرمّز محلي (ملف `ffmpeg.dll` موجود وغير مستخدم) | `04` |
| المشروع | لا ملف محلي: JSON سحابي (`project-data`) + حفظ تلقائي `PUT` كل 2000ms | `01` |
| أنماط الرسم | **نمطان فقط** (Illustrate / Reveal) + مجموعتا مؤشرات | `03` |
| حدود | صوتان كحد أقصى للمشهد · سكريبت 14:59 · 250 صورة · 18,000 ثانية صوت | `06` |
| أمان | `nodeIntegration: true` · `sandbox: false` · DevTools مفتوح في الإنتاج · توكنات نصية · Mixpanel بـ`ignore_dnt` | `06` |

### 1.2 الحكم: ما نأخذه / ما نتركه
| نأخذ (فكرة/خوارزمية) | نترك (التنفيذ) |
|---|---|
| مفهوم **السلوكيات الأربعة** للمشهد (دخول/تأكيد/خروج/وقفة) | ماسك البكسل للرسم (لا يعطي تحكمًا حقيقيًا) |
| **ترتيب الجزر** كمرجع مبدئي للرسم | الترتيب الصفّي الأعمى (لا يفهم بنية الشكل) |
| **تزامن الكلمات** (`wordBoundaries`) | التزامن السحابي (نحن نحسبه محليًا من TTS/Whisper) |
| فكرة **سماكة الخط من التآكل** | حسابها ببكسلات مربوطة بـ500px |
| الكاميرا واللوح (2×2) — ونحن نطوّرها | لا مُرمّز محلي · 25fps · 720p · سحابة إلزامية |
| مفهوم «المشهد = صوت + عناصر» | اعتماد كامل على مزوّد واحد مغلق |

## 4) القرار التقني الحاسم: من الرستر إلى المتجهات

**ما لديك اليوم**: المسار يُكتشف بكسليًا (`skeletonize` على صورة). يعمل، لكنه لا يسمح بـ:
ضبط سرعة الرسم · تلوين كائن-بكائن · كتابة الحروف · إعادة استخدام المسار في ستايل آخر · رسم عند 60fps بجودة مثالية.

**المطلوب**: مسار واحد = كائن رياضي `path d="M… C…"` بخاصية `length`.

```
SVG/صورة
  ↓ (مصادر: SVG أصلي | تحويل صورة: تدرّج رمادي → عتبة/حافة → potrace/VTracer → مسارات)
مسارات متجهية
  ↓ تنظيف (حذف المسارات < عتبة · دمج · إغلاق فراغات)
قياس (طول كل مسار + نقاط أخذ العينات بتكيّف مع الانحناء)
  ↓ ترتيب: greedy(أقرب بداية + استمرارية اتجاه) → تحسين 2-opt
جدول زمني: t(p) = t_start + (L_p / v)        v ≈ 900 وحدة/ث على لوح 1000
  ↓ تعديل: الخطوط المستقيمة الطويلة أسرع، الانحناءات أبطأ (محاكاة يد)
سماكة متغيرة: عرض القلم يتغير مع السرعة والاتجاه (شرطة حبر/ماركر/طبشور)
  ↓ ملء الكائنات بعد إتمام المحيط (أو تظليل hatch حسب الستايل)
مخرجات: ملف `.rstrokes.json` لأي أصل (يُخزَّن مع الأصل ويُعاد استخدامه)
```

**النص كمسارات (أهم ميزة تفوق):**
```
نص عربي → uharfbuzz (تشكيل + ربط + اتجاه RTL/LTR) → fontTools (مخططات الحروف)
→ لكل حرف: هيكل مركزي (medial axis) → مسار/عدة مسارات مرتّبة بترتيب الكتابة
→ رسم بحبر متغير العرض  ⇐ يبدو كأن يدًا تكتب فعلًا (وليس قناعًا بكسليًا)
```
بديل أسرع (fallback): رسم محيط الحرف المغلق كاملًا ثم ملؤه — نفس أسلوب الوايت بورد الكلاسيكي.

**لماذا هذا مهم:** VideoScribe نفسه لا يكتب الحروف — بل يكشف صورة محروقة. ومن هنا: **الكتابة الحقيقية = ميزة لا يملكها أي منافس**، ومعها نتحكم في سرعة الكتابة وضغط الحبر وربطها بنطق الكلمة.

**المكتبات المطلوبة (كلها Python نقية، بلا تثبيتات نظام):** `uharfbuzz` · `fontTools` · `shapely` · `pyclipper` (توسيع المسار للسماكة) · `scikit-image` (موجود) · `opencv-python` (موجود) · `vtracer` (بديل: potrace عبر Node/wasm).

## 6) وحدة البحث الحقيقي — أهم ما سألتَ عنه

### 6.1 المبدأ: البحث **من الفهم** لا من الكلمات
```
السكريبت
  → فهم (كيانات + أحداث + أرقام + اقتباسات + ادّعاءات)
  → لكل كيان: "ورقة احتياج" (What do I need?)
       شخص  → صورة · تاريخ ميلاد/وفاة · وصف مختصر · اقتباس مشهور
       دولة → علم (SVG) · خريطة · سكان · سنة الاستقلال · موقع
       حدث  → صور تاريخية · خريطة المتحاربين · خط زمني · أرقام الخسائر
       مفهوم/مصطلح → شرح مبسط · مثال · رسم تخطيطي
  → توليد استعلامات دقيقة (SPARQL + بحث وسائط) — لا كلمات مفتاحية من النص
  → تنزيل → بوابة ترخيص → تنظيف → تسجيل منشأ → تخزين مؤقت
```

### 6.4 بوابة الترخيص + المنشأ (تُنفَّذ آليًا)
```
لكل ملف: license ∈ {PD, CC0, CC-BY(+نسبة), CC-BY-SA(ممنوع افتراضيًا), MIT/Apache(للأصول الرقمية), OFL(خطوط)}
+ تُرفض تلقائيًا: NC · ND · «غير معروف» · «يُحددها المستخدم» عند الاستيراد التلقائي
+ يُسجَّل: sourceUrl · author · retrievedAt · sha256 · license snapshot (نص الرخصة كما كانت لحظة السحب)
+ يُنشأ assets-credits.json تلقائيًا ويُدمج في وصف الفيديو
+ cache مشترك بين المشاريع: نفس الصورة لا تُنزَّل مرتين (توفير وتكلفة)
```

### 6.5 سلسلة البدائل عند غياب الأصل
```
1) هل يوجد أصل PD/CC0 مطابق؟        → استخدمه
2) هل يوجد CC-BY صالح؟              → استخدمه + نسبة إلزامية
3) هل يمكن توليد رسم بسيط بالكود؟   → نعم (أيقونة/سهم/كارت/خريطة) → ارسمه
4) هل يمكن توليد صورة AI؟           → نعم (FLUX-schnell) + تحويل لستايلنا
5) غير ذلك                          → استبدل المشهد بصريًا (بطاقة/نص) وسجّل السبب
```
> بهذا لا تتوقف أبدًا («لا أصل» ليست نهاية)، وفي نفس الوقت لا ندخل بأصل مجهول الترخيص.

### 7.2 مراحل خط الصوت
```
النص (من السكريبت أو من لوحة القصة)
  → [مسار A] رفع تسجيلك → تحويل صيغة + تطبيع مستوى
       → faster-whisper (نمط align=True) → توقيت كل كلمة
  → [مسار B/C] TTS → يعطي Timestamps جاهزة (كلمة/حرف)
  → توحيد التوقيت إلى: [{ word, start, end, charStart, charEnd }]
  → موسيقى: اختيار مزاج من المشهد (حزمة CC0) + ducking تلقائي −12dB تحت الكلام
  → مؤثرات: من الحزمة (كاميرا/ورق/كاتبة/بوينغ/تسميع) موزّعة على الأحداث البصرية
  → مزج: 48kHz · هدف −14 LUFS · ذروة −1 dBTP · تقليل ضوضاء خفيف للميكروفون
  → ملف voice.wav + audio.mix.wav + timings.json
```

### 7.3 مزامنة الكلمات ← الصورة (هذه «العصا السحرية»)
```
لحظة نطق الكلمة "نابليون" = 00:12.40
→ الأصل المرتبط بها يُنهي رسمه عند 00:12.30 (قبلها بـ100ms)
→ التسمية المكتوبة تُكتَب في 00:9.80–00:12.40 (تزامن الكتابة مع الكلام)
→ العنصر يُؤكَّد (emphasis) عند تمام الكلمة
```
هذا ينقلنا من «رسم يشتغل بالتوازي مع صوت» إلى **فيديو مُخرَّج** — وهو ما لم يفعله VideoScribe إلا بحدود سحابية.

## 10) الناقد الآلي (حلقة الجودة) — ما يجعلنا «أقوى من الآخرين»

```

 1) فحص تقني: صمت > 0.6 ث؟ كادر مزدحم؟ نص غير مقروء؟ دقة/معدل إطارات؟ صوت clipping؟
 2) فحص سردي (LLM على لوحة القصة + عيّنات إطارات): هل الخطاف قوي؟ هل المعلومة واضحة؟

 3) إصلاح تلقائي: تقصير جملة · إضافة تعليق · تغيير كاميرا · إعادة ترتيب مشهد · تكبير خط
 4) تكرار حتى اجتياز العتبات (بحد أقصى دورتين لتجنب الحلقات اللانهائية)
 5) تقرير لك: «3 نقاط ضعف وتم إصلاحها» — التعلم من كل فيديو يُخزَّن في قواعد الأسلوب
```
