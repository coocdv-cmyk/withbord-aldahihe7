# راسم — الاستراتيجية الكاملة
**الهدف: أقوى تطبيق فيديوهات وايت بورد بالذكاء الاصطناعي في العالم — «السهل الممتنع»**
الإصدار 1.0 · أكتوبر 2026 · المشروع: `rasm-pro`

---

## 0) الخلاصة في عشرة أسطر

1. **محرك محلي** (Cairo/Pango + ffmpeg) = رسم وتصدير بلا حدود وبلا تكلفة وبلا إنترنت، وبجودة لا يقدمها أي منافس.
2. **ذكاء أونلاين** (LLM + توليد صور + TTS) = سرعة وجودة فوريتان بدون انتظار عتاد.
3. **مكتبة أصول ضخمة ونظيفة قانونيًا** (تم سحب **318,823 أيقونة فريدة** من 190 مجموعة مفتوحة بترخيص موثّق + **52,256 ملف SVG جاهز للرسم**).
4. **بيانات وصفية ملكية**: ترتيب رسم + وسوم عربية + ألوان + زمن رسم — لا يملكها أي منافس.
5. **8 ستايلات** بهوية كاملة (ألوان + خط عربي + قلم + نسيج + مؤثرات).
6. **شاشة واحدة**: فكرة → فيديو. صفر إعدادات إلزامية.
7. **تصدير خارق**: 4K/60fps، عمودي/أفقي، AV1، Alpha، ترجمة محروقة — كل ذلك على جهازك.
8. **الإنتاج للملايين**: نظام قوالب + خطافات + نشر يومي مدروس (لا انتظار للكمال).
9. **التكلفة**: 25–40$ للشهر الأول كله، ثم تنزل إلى 0$ مع التوليد المحلي.
10. **الخندق**: التكامل بين (مكتبة موسومة) × (محك يتقن العربية) × (خط إنتاج كامل بضغطة) — مجتمعين، لا أحد يملكهم مجتمعين.

## 1) القرار الاستراتيجي: أونلاين أم محلي؟

**الجواب: هجين. وهذا ليس ترددًا — هذه أفضل هندسة ممكنة.**

### القاعدة الحاكمة
> **الأونلاين يفكّر ويولّد ويجمّع. المحلي يرسم ويركّب ويصدّر.**

### جدول القرار (لكل مهمة: المزوّد الآن + البديل المحلي)

| المهمة | أونلاين (الآن — سرعة وجودة) | محلي (لاحقًا — صفر تكلفة) | القرار |
|---|---|---|---|
| تجميع الأصول | Iconify · Openverse · Smithsonian · Met APIs | بعد التنزيل: المكتبة محلية | أونلاين مرة واحدة → تُخزَّن محليًا |
| فهم النص وتقسيمه | Gemini 2.5 Flash / GPT-mini (سنتات) | Qwen3-4B عبر Ollama | أونلاين (أسرع وأذكى) + بديل محلي |
| توليد المشاهد والشخصيات | fal.ai (FLUX-schnell) ≈ 0.003$/صورة | SDXL/FLUX محلي إذا توفّر GPU | أونلاين (لا يحتاج عتادًا) |
| تحويل الصورة لمسارات | — | VTracer / potrace (محلي، سريع) | **محلي دائمًا** |
| ترتيب الرسم والتوقيت | — | خوارزمياتنا | **محلي دائمًا** |
| الأصوات (TTS) | ElevenLabs (سينمائي) / Azure Neural (رخيص + 5 لهجات عربية) | Piper (مجاني، جيد) | ElevenLabs للمحتوى البطل · Azure للكمّ |
| توقيت الكلمات | من خدمة الصوت نفسها (Timestamps دقيقة) | faster-whisper كبديل | من خدمة الصوت (أسرع وأدق) |
| الوسوم العربية + البحث | — | Qwen3-4B + CLIP | **محلي دائمًا** (318 ألف أصل = مستحيل أونلاين) |
| الموسيقى والمؤثرات | مرة واحدة من مكتبات CC0 | تُخزَّن محليًا | **محلي** |
| الرسم والحركة والتصدير | ❌ غير موجود | Cairo/Pango + ffmpeg | **محلي دائمًا — قلب المنتج** |

### لماذا هذا الترتيب بالذات؟
- **التكرار**: أنت ستولّد آلاف التجارب. أي شيء مدفوع/شبكي في مسار الرسم = خسارة.
- **الجودة**: أفضل نماذج التوليد والصوت تحتاج GPU لا تملكه الآن → نستأجرها بالثانية (سنتات) بدل شراء جهاز.
- **الاستقلال**: المحرك محلي ⇒ المنتج يعمل بلا إنترنت، ولا يستطيع مزوّد «غلق الباب» عليك.
- **الخصوصية**: نصوص المستخدم لا تُرسَل إلا للضرورة، وبإذنه (عكس VideoScribe الذي يرسل كل شيء لجهات ثالثة).

> **المستقبل**: كل مزوّد أونلاين يمر عبر **طبقة تجريد** (`providers/`) — نستبدله بأي مزوّد آخر أو بمحلي بأمر واحد. لا ارتهان.

## 2) فلسفة «السهل الممتنع»

| مبدأ | التطبيق |
|---|---|
| شاشة واحدة | مربع نص + زر واحد «اصنع الفيديو». كل شيء آخر تلقائي. |
| صفر إعدادات إلزامية | المستخدم لا يرى Timeline إلا إذا فتح «وضع الخبير» بنفسه. |
| القرار الذكي | النظام يختار الأصول، الإيقاع، الصوت، الموسيقى، الترجمة، ويتصرف نيابة عن المستخدم. |
| لا كماليات مكسورة | كل زر يعمل من أول مرة. لا خطوات ناقصة. |
| العربية أولًا | واجهة RTL، تشكيل صحيح (HarfBuzz)، خطوط عربية جديرة، أصوات عربية بلهجات. |
| شفافية | صفحة «لماذا اخترت هذا؟» تشرح قرارات النظام — ثقة المستخدم. |

**القاعدة**: أي ميزة تحتاج شرحًا أكثر من 20 ثانية = ميزة فاشلة. أعِد تصميمها أو احذفها.

## 6) المحرك (خُلاصة التشغيل)

```
scene.json
├─ canvas: 1920×1080 (أو 1080×1920 عمودي)
├─ style: ink_qalam
├─ voice: { provider, voiceId, timestamps[] }
└─ scenes[]
    ├─ text: "سطر الشرح"
    ├─ duration: auto | ثواني
    ├─ elements[]: { assetId, order, startAt, colorSlot, effect }
    └─ transition: wipe | slide | none
```

- **الرسم**: كل مسار يُقسَّم لنقاط، والعلم يُحرَّك على المسار بسرعة تخطيط ثابتة (تشبه اليد البشرية ≈ 900 وحدة/ثانية على لوح 1000).
- **القلم**: يتبع آخر نقطة مرسومة، ويميل مع اتجاه الحركة، ويتغير حجمه مع سرعة الرسم (طبيعية).
- **التوقيت**: كل مشهد = `max(زمن الصوت, زمن الرسم)` مع قواعد: إن طال الصوت ⇒ إبطاء الرسم؛ إن طال الرسم ⇒ وقفة صغيرة ثم استئناف.
- **التزامن الدقيق**: الكلمة تُرسَم/تُلوَّن لحظة نُطقها (من Timestamps خدمة الصوت مباشرة).
- **التصدير**: ffmpeg — H.264/H.265/AV1، 1080p/1440p/4K، 30/60fps، أفقي/عمودي/مربّع، Alpha (ProRes 4444 / VP9)، SRT + ترجمة محروقة.

## 9) استراتيجية يوتيوب للملايين

> **الحقيقة الصريحة**: الملايين لا تأتي من الجودة وحدها. تأتي من:
> (فكرة مطلوبة) × (خطاف قوي) × (انتظام يومي) × (صبر 3–6 أشهر) × (تحسين مستمر بالأرقام).

### الجدول المطلوب
- **1 شورت يوميًا** (35–55 ثانية) + **1–2 فيديو طويل أسبوعيًا** (5–8 دقائق).
- 8–10 قطع أسبوعيًا. **الانتظام أهم من الكمال**.
- كل فيديو يُنتج نسختين: عمودي + أفقي (نفس المشروع، بأمر واحد).

### المحاور السبعة (اختر 2 للبداية، لا 7)
1. عقل وذاكرة، 2. مال ومشاريع صغيرة، 3. صحة يومية، 4. تاريخ وحضارة، 5. لغة عربية وأخطاء شائعة، 6. تقنية وذكاء اصطناعي، 7. قصص نجاح.

### صيغة الشورت (قالب ثابت)
| الثانية | الحدث |
|---|---|
| 0.0–1.5 | الخطاف: سؤال مرئي + كتابة سريعة لكلمتين |
| 1.5–8 | 3 حقائق/نقاط مرسومة سريعة (رسم + كلام متزامن) |
| 8–40 | التوسّع: مثال → دليل → تصحيح خطأ شائع |
| 40–52 | الخلاصة على شاشة واحدة + CTA («اكتب رأيك» أو «تابع الجزء 2») |

### قوالب العناوين (5 قوالب × نسخ لا نهائية)
1. «ليه …؟» — 2. «3 أخطاء تخليك …» — 3. «إزاي … في 30 ثانية» — 4. «الحقيقة عن …» — 5. «لو عندك … اعمل …».

### الصور المصغرة (Thumbnails)
- 3 كلمات عربية بالضخم + سهم دائري + لون أكسنت واحد فقط.
- اختبار A/B **يومي**: صورتان لكل فيديو، استبدل بعد 48 ساعة إذا CTR < 6%.
- لا تستخدم صورًا مأخوذة — استخدم مخرج راسم نفسه (اتساق الهوية).

### ما يصنع الملايين فعليًا (مُجرَّب على القنوات الكبرى)
قوائم مرقّمة · «قبل/بعد» · أرقام مفاجئة · «ممنوعات» · تصحيح مفاهيم شائعة · «الجزء 1 من 100» (سلاسل تبني عادة مشاهدة).

### مؤشرات القرار (لا تجادل بالرأي — بالأرقام)
| المؤشر | المستهدف (شورتس) | الإجراء عند الخصارة |
|---|---|---|
| CTI/CTR | > 6% | غيّر الصورة المصغرة والعنوان فقط (لا المحتوى) |
| مدة المشاهدة المتوسطة | > 55% | اهتم بالخطاف (أول 3 ثوان) |
| تحويلات/متابعات لكل ألف مشاهدة | > 10 | ثبّت السلاسل واذكرها صوتيًا |
| فيديو «انفجر» | أي فيديو > 100 ألف | اصنع منه 5 نسخ بنفس القالب فورًا |

## 12) المخاطر وخطة العلاج

| الخطر | العلاج |
|---|---|
| ترخيص أصل غير واضح يتسلل | بوابة آلية + بصمة + مصدر لكل أصل + إمكانية سحب مجموعة كاملة بأمر |
| «تبدو مجموعة أيقونات مجانية» | توحيد الستايل إجباري قبل الشحن (لا أصل بلا معالجة) |
| اعتماد على مزوّد أونلاين واحد | طبقة تجريد `providers/` + بديل محلي لكل مزوّد |
| المزود لا يقبل الدفع من مصر | fal.ai / Replicate / OpenRouter يقبلون البطاقات الدولية أو عبر وسيط |
| ملل/انقطاع الإنتاج | قوالب + دفعات أسبوعية + نشر مجدول + مؤشر أرقام يومي |
| تشابه مع منافس | قواعدنا: لا كود ولا أصول ولا اسم من VideoScribe — كل شيء مبني عندنا |
| ضعف الاحتفاظ | نغيّر الخطاف لا المحتوى · أضف «معلومة جديدة كل 5 ثوان» |
