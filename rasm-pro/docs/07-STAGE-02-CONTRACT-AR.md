## 1. الهدف

ثلاثة مخرجات فقط:

1. **عقد مشروع واحد** (`project.json`) + عقد خطة موثّق + ترحيل آمن.
2. **قاعدة زمن واحدة**: الصوت هو الساعة، و`fps` كسر عقلاني، ولا تمدد صامت.

**خارج النطاق:** ربط الأدلة/الأصول (المرحلة 3)، استيراد الصوت (4)، SFX الحقيقية (5)،
السرد والقوالب (6)، الواجهة (7)، الإنتاج الطويل (8)، التغليف النهائي (9).

### المانيفست

`project.json` في جذر المشروع، `schema_version: "1.0"`، ويشمل:
الهوية، اللغة، اللوحة، `fps {num,den}`، الصوت (مسار/هاش/عينة/إجمالي)، النص،
البحث، الخطة النشطة + هاشها، سياسة الأصول، الحالة، `unresolved[]`، الرندرات،
مرجع Studio. كل المسارات نسبية.

### قواعد

- المانيفست هو نقطة الدخول؛ لا نسخ للمحتوى داخله.
- `storyboard.active` يحدد الخطة النشطة؛ النسخ القديمة تبقى.
- الحالة: `draft → researched → planned → approved → rendered`.
- الأصول: `origin`, `license`, `approved_by`, `approved_at` (تملأها المرحلة 3).
- كتابة ذرية، UTF-8، ومقارنة بالهاش لا بالتاريخ.
- الترحيل: `--dry-run` افتراضيًا، نسخة قبل `--apply`، وكتابة المانيفست فقط.

## 4. المسار B — قاعدة الزمن وأحداث القلم

### المبدأ

مرجع الزمن = عينة الصوت (عدد صحيح) + `fps` كسر عقلاني. حدود المشاهد مطلقة،
والتحويل إلى إطارات يتم مرة واحدة عند الحدود التراكمية — لا تقريب لكل مشهد.

### التغييرات

- `engine/stages/plan.py`
  - `build_plan(..., fps=...)`، وإزالة `FrameRate(30)` الثابتة.
  - عند المحاذاة: `start_sample`, `end_sample`, `duration_samples`,
    `duration_frames` مشتقة على fps الخطة.
  - `plan["fps"] = {"num": ..., "den": ...}`.
- `engine/render/director.py`
  - رفض تعارض fps بين الخطة والرندر (`TimebaseError`) بدل التمدد الصامت.
  - حدود مشاهد مطلقة (`scene_bounds`) من العينات/الإطارات/الثواني التراكمية.
  - لا تمدد مشهد صوتي ليتسع للرسم؛ يُعلَّم `overflow` بدل ذلك.
  - أحداث القلم تحمل `frame` و`sample` و`t` المطلق.
- `engine/stages/validate_plan.py`
  - تحقق من `fps` العقلاني، استمرارية العينات، واتساق `duration_frames`.
- `engine/render/video.py`
  - دعم `fps` ككسر عقلاني في `-r`.
- `rasm.py` و`studio/app.py` و`studio/rasm_bridge.py`
  - الافتراضي = fps الخطة، لا 24/30 ثابتة.

### قبول المسار B

- [x] خطة 30 دقيقة على 24/30/29.97 → انزلاق 0 إطار.
- [x] فرق الصوت/الفيديو ≤ إطار واحد.
- [x] خطة 30 + رندر 24 → خطأ واضح، لا تمدد 25%.
- [x] أحداث القلم داخل حدود المشهد و±1 إطار.
- [x] رندر ww1 الحالي بنفس المدة.
- [x] كل الاختبارات القديمة + الجديدة ناجحة.
