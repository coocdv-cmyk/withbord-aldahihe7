# خطة العمل الشاملة — محرّك يتكيّف مع أي سكريبت

> **التاريخ:** 21 أكتوبر 2026 · **الفرع:** `stage6-contract`
> **التفويض:** المالك يفوّض التنفيذ الكامل (خطة، إصلاحات، قوالب، أفلام تجريبية) حتى الإغلاق.
> **القاعدة:** لا يُغلق أي بند إلا بدليل مقيس + اختبار + مراجعة بصرية.

---

## 0. التشخيص: لماذا لم يكن «يتكيّف مع أي سكريبت»

| العيب | الأثر | الدليل |
|---|---|---|
| **الأدوار من رقم المشهد** (1=hook، كل ثالث=explain، الأخير=close) | الصورة تصيب مشهد `explain` بلا مكان لها؛ اضطررتُ إعادة ترتيب 18 مشهدًا يدويًا | `engine/stages/families.py:scene_role` |
| **تخطيط واحد لكل دور** | 18 مشهدًا متتاليًا = 18 لقطة شبه متطابقة | `plan.py` `_text_slot` |
| **التعليق/التغليف ثابتان** | قصّ النص على الشاشة | أُصلح (قياس) |
| **قاعدة زمن واحدة (كلمة/ثانية)** | لا يصلح لفيديو صامت ولا لسكريبت طويل | `plan.py` |
| **6 أنواع مؤثرات من 3 تسجيلات** | لا انتقال بين المشاهد، ولا إحساس «الحدث» | `engine/audio/sfx.py` |
| **لا فحص تركيب آلي** | المراجعة بالعين فقط | — |

---

## 1. ستّة مسارات عمل، لكلٍّ بوابة قبول

### W1 — الأدوار من **المحتوى** لا من الرقم
* `resolve_roles()`: دور صريح من السكريبت > استنتاج (سؤال ⇒ hook، دليل مصوَّر ⇒ evidence، خاتمة ⇒ close، غير ذلك explain).
* **بوابة**: `tests/test_scene_roles_from_content.py` — 6 حالات (أول/آخر/صورة/سؤال/خاتمة/صريح).

### W2 — تنويع القوالب: **مخططات** لا وصفات
* كل دور يختار **مخططًا** (variant) لا ثابتًا: صورة يمين/يسار/عرض كامل، جملة وسطية/يسار/بطاقة اقتباس.
* **بوابة**: لا تكرار بين مشهدين متتاليين (مقياس: اختلاف مستطيل العناصر) + `tests/test_layout_variants.py`.

### W3 — عمق التصميم
* بطاقات عناوين (chapter cards) · أشرطة لاصقة (tape) · أختام (stamp) · شبكة ورق · تظليل متدرّج.
* **بوابة**: لقطة 联系 لستة أنماط مختلفة + مراجعة بصرية.

### W4 — المؤثرات «القوية»
* صوت **انتقال** بين المشاهد · ربط أدوار جديدة بالمحركات نفسها (الأختام/الشريط) · **ducking** تلقائي مع السرد · تقرير مزج أدقّ.
* **بوابة**: `tests/test_sfx_transitions_contract.py` + تقرير مزج يذكر الأحداث.

### W5 — فحص تركيب **آلي** (يجعل المراجعة قابلة للتكرار)
* أداة: لكل مشهد → نسبة الحبر، تداخل العناصر، تجاوز النص لصندوقه، فراغ، وتكرار مع المشهد السابق.
* **بوابة**: تقرير `qa/<project>/composition.json` + أداة تفشل عند تداخل.

### W6 — أربعة أفلام (عربي + إنجليزي)
1. `episode-01-ar` (عربي، بصوت مولَّد) — إعادة إنتاج بعد W1..W5.
2. `episode-02-art-of-war` (إنجليزي، صامت) — إعادة إنتاج.
3. `episode-03-ar` (عربي، جديد: موضوع مختلف، قالب مختلف).
4. `episode-04-en` (إنجليزي، صامت، منهج مختلف: شرح/مقارنة).
* **بوابة**: 4 مخرجات · 0 تداخل · 0 تجاوز نص · AV = 0.000ث · 0 انزياح.

## 2. ترتيب التنفيذ (اعتمادي)

```
W1 (الأدوار) → W2 (التنويع) → W3 (التصميم) → W4 (المؤثرات) → W5 (فحص التركيب)
   → W6 (4 أفلام) → مراجعة بصرية نهائية → تقرير الإغلاق
```

> كل مسار يُختبر ويُودَع قبل الانتقال للتالي. الاختبارات تبقى خضراء عند كل بوابة.

---

## 3. ما لا يُعدّ إنجازًا

- «الفيديو بدا جميلًا» بلا فحص تركيب آلي (W5).
- «المحرك يعمل» على سكريبت واحد فقط — يُقاس على 4.
- نسبة جاهزية بلا قياس.
- أي عدد «ممتاز» بلا رقم.
