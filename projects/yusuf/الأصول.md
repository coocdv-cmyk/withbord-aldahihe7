# أصول فيديو «يوسف عليه السلام» — الجرد الكامل 📦

> **الاستراتيجية**: مكتبة أصول مجانية أولًا (SVG خفيف + رخصة نضيفة) → اللي مش موجود: توليد AI + سكينة rembg → الرموز الهندسية: رسم برمجي مباشر.
> **الرمز**: `م` = مكتبة مجانية | `ت` = توليد AI | `ر` = رسم/تركيب برمجي | `ص` = شخصية قالب (يُبنى مرة ويُعاد استخدامه بإعادة الوضع/القلب).
> **قاعدة الستايل**: كل أصل يمرّ على «التطبيع» (خط أسود موحّد + ألوان مسطحة + خلفية شفافة→بيضا) قبل الدخول للمكتبة.
> **بلا ملامح للجميع** + ملصق اسم عربي لكل شخصية يُضاف وقت تكوين المشهد (مش مدموج في صورة الأصل).

## إحصائية
- **الإجمالي: ~84 أصل** (≈ 20 شخصية قوالب + ≈ 45 عنصر مشهد + ≈ 19 رمز/خلفية).
- الأصعب (اللي التوليد فيها بيدخل): الشخصيات (قوالب محدودة العدد) + القمصان + لوحة بني حسن + بحر يوسف.
- الأسهل (مكتبات جاهزة أو رسم برمجي): البئر، الجمل، السكاكين، الفواكه، الجرار، السنبلة، النجوم، الرموز كلها.

## خطة التنفيذ
1. **جمع الأصول** (2.5): تحميل Excalidraw libs + openclipart → فلترة المطلوب من القائمة.
2. النواقص: دفعة توليد (SD + rembg) — مش 84 عنصر، المتوقع ~25-35 بس.
3. **تطبيع الستايل** لكل الأصل → `assets/approved/`.
4. مشهد تجريبي واحد (S31 — قطعن أيديهن) نراجعه مع بعض قبل الإنتاج الكامل.
5. ثم: 54 مشهد → كليبات → تجميع.
