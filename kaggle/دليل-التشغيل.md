# دليل تشغيل Kaggle — توليد مكتبة العناصر (المرحلة 2)

الهدف: نطلع **84 صورة** (28 عنصر × 3 نسخ) بنفس الستايل، ونختار منهم الأحسن، وتبقى دي مكتبة العناصر الدائمة.

---

## قبل ما تبدأ (مرة واحدة بس)

1. اعمل حساب مجاني على **kaggle.com** (بجوجل أو إيميل).
2. فعّل **توثيق رقم التليفون**: من الصورة الشخصية → `Settings` → `Phone verification`.
   - من غيره: **مفيش إنترنت ومفيش GPU مجاني** جوه النوت بوك.
3. الوقت المتوقع للتحضير: 10–15 دقيقة.

## التشغيل (كل مرة عايز تولّد)

1. من الصفحة الرئيسية في Kaggle: **Create → New Notebook**.
2. في النوت بوك الجديد: **File → Import Notebook** → اختار الملف ده من جهازك:
   `D:\withbord inmation\kaggle\whiteboard-elements.ipynb`
3. من قائمة **Settings / Session options** (على اليمين):
   - **Internet = On** ← مهم جدًا (تنزيل موديل الصور ~2 جيجا)
   - **Accelerator = GPU T4 x2** (أو أي GPU المتاح)
4. دوس **Run All** (تشغيل كل الخلايا).
5. استنى، والتاب مفتوح:
   - تنزيل الموديل: 1–3 دقايق
   - التوليد: تقريبًا **3–8 دقايق** لـ 84 صورة
6. لما كل الخلايا تخلص: من تبويب **Output** → نزّل:
   - `elements_batch.zip` ← الصور
   - `contact_sheet_master.png` ← لوحة واحدة فيها كل العناصر (للاستعراض والاختيار)
7. فك ضغط الـ zip في المجلد ده على جهازك:
   `D:\withbord inmation\elements\batch1\`
8. قول للاسيستنت **"وصل"** — وهيجهّز سكريبت الاستلام والاختيار.

## لو حصلت أي مشكلة

| المشكلة | الحل |
| --- | --- |
| رسالة "مفيش GPU" | Settings → Accelerator = GPU، واعمل Run All تاني |
| فشل تنزيل الموديل | Settings → Internet = On، وشغّل تاني |
| الجلسة قطعت (وقت طويل) | اعمل Run All تاني — التوليد نفسه سريع |
| بطيء في الأول | ده تحميل الموديل، مرة واحدة في الجلسة |

## ملاحظات مهمة

- **متحاولش ترفع النوت بوك كملف مشروع** — هو ملف واحد بيتبعت لKaggle مباشرة زي ما الشرح فوق.
- لو عايز تعدّل قائمة العناصر (تزيد/تنقص): عدّل `kaggle\elements_list.csv` وقول للاسيستنت يبني النوت بوك تاني (أمر واحد).
- لو عايز أقوى ستايل: بنحدد LoRA مناسب ونحط اللينك بتاعه في خانة `LORA_URL` جوه النوت بوك (مع مراجعة رخصته).
- تقدير الخطة كان "3–5 أيام" للمرحلة دي — بإذن الله هتخلص أسرع بكتير لأن النوت بوك جاهز بالكامل.
