## 4. نقطة الإقلاع (Boot)

`build/index.html` (1,788 بايت) — لاحظ:

1. تحميل `assets/polyfills-*.js` ثم `assets/index-*.js`.
2. تعليق صريح: `AWS Cognito library expects global to be defined` → `window.global = window`.
3. `<noscript>` يحتوي على **Google Tag Manager** (`GTM-WL6S7Z` عبر نطاق `ssgtm.videoscribe.co`) و**Facebook Pixel** (id `1066541273357327`).
4. `<body class="videoscribe">` والجذر `<div id="root" class="Root">`.

`src/js/index.tsx` يوضّح سلسلة التهيئة:

```tsx
initPixiExtensions();                                   // امتدادات Pixi
initSentry({ dsn: config.SENTRY_DSN, ... });            // مراقبة الأخطاء
// ثم الشجرة:
StyledEngineProvider → ThemeProvider → ErrorBoundary → Provider(store)
  → ConnectedRouter(history) → RendererContextProvider → App
  + <GoogleTagManager /> + <Facebook />
```

ملاحظات مهمة:
- `import 'pixi.js/unsafe-eval'` — يستخدمون مسار Pixi السريع (unsafe-eval) بدلًا من المحلّل الآمن.
- `initializeElectronReduxBridge()` — جسر بين عملية Electron الرئيسية ومخزن Redux.
- `RendererContextProvider` — يحدّد إن كان التطبيق في **وضع الرندر** (CloudRenderer) أو وضع المحرر العادي.

- **تقسيم بالتحميل الكسول**: `HomeView`, `AuthenticationRouter`, `RendererView`, `EditorView`, `PreviewView` كلها `lazy()`.
- **وضع الرندر محسَّن**: عند `isRenderPath` تُلغى مستمعات الشبكة (`online/offline`)، ومقارنة هوية المستخدم، وتكامل SleekNote — «لتسريع الرندر» (تعليق صريح في `App.tsx:67`).
- **بوّابات**: قبول الشروط والتسويق (`AcceptTermsAndMarketing`)، تحذير عدم الاتصال (`OfflineWarning`)، و`NoOnlineStorage` — أي أن التطبيق يعمل بلا تخزين سحابي أحيانًا.

- **تجارب A/B وخصائص المستخدم**: `OptimizelyProvider` يُمرَّر فيه `userTier`, `accountType`, `email`, `application`, `applicationVersion` — أي أن **كل شيء تقريبًا قابل للتجريب** من جهة الخادم (تسعير، حدود، واجهة).
- **التحقق من الجلسة عند الإقلاع**: `dispatch(validateToken(...))`، ومقارنة `cookieUserId` بـ `reduxUserId` وإعادة تحميل الصفحة عند الاختلاف.
- **معلومات استهلاكية**: `SleekNote` (نوافذ تسويقية داخل التطبيق) و`Callout` (دعوات للترقية).

## 4.ج المشاركة والمعاينة العامة (Public Sharing)

من `src/js/preview/PreviewView/index.tsx` (276 سطرًا) و`src/js/preview/PreviewView/Cta.tsx`:

- **الرابط العام** `/preview/:publicSharingId` لا يحتاج تسجيل دخول. يجلب البيانات من `appServices.getProjectForPreview(publicSharingId)`.
- **استجابة الخادم** (`PreviewProjectData`): `{ title, useWatermark, modifiedDate, signedUrls[], projectModel, projectOwnerAccountType }` — أي أن *قرار العلامة المائية يأتي من الخادم*، والأصول تُسلَّم عبر **روابط موقّعة مؤقتة (signed URLs)** لا ملفات مضغوطة.
- **نفس محرك التشغيل** يُستخدم في المعاينة العامة: `PlayerContextProvider` + `PreviewPlaybackLoader` — أي أن محرك Pixi يعمل في المتصفح العادي أيضًا (ليست تجربة منفصلة).
- **حلقة نمو (viral loop)**: الزائر غير المسجّل يرى `Cta` (تجربة مجانية) + خلفيات توضيحية + UTM مخصّصان (`PREVIEW_SHARING_UTM_NAV` و`PREVIEW_SHARING_UTM_CTA`) لتتبّع كل زيارة قادمة من رابط مشاركة.
- المستخدم المسجّل المجاني يرى بانر ترقية (`UpgradeBannerContent`) داخل نفس الصفحة.
- **فرصة للمنافس**: المشاركة الحالية تعتمد كليًا على خوادم Sparkol (login + signed URLs + حصة). البديل الأقوى: تصدير «ملف مشروع واحد» أو صفحة HTML مستقلة تعمل بلا سيرفر، ومعاينة offline-first.

## 7. أبرز ملامح المعمارية (ما يجب على المنافس معرفته)

1. **كل شيء محلي أولًا**: التشغيل والرسم والتصدير يحدث داخل الجهاز (Pixi + WebCodecs + WASM)، والسحابة للمصادقة/المكتبة/الرندر الاختياري فقط. هذا يجعل منتجًا محليًا بالكامل (بلا حساب) قابلًا للتنفيذ ويسهل تجاوزه.
2. **فصل صريح لمحرّك التشغيل**: `playback/pixi-player` وحدة مستقلّة تُستخدم في المحرر وفي المعاينة وفي الرندر — أي أن نفس المحرك يشغّل كل شيء. هذا تصميم صحيح ويجب تقليده.
3. **معالجة صور ثقيلة في Worker**: `ImageProcessor.worker` (988 KB) و`AudioEncoder.worker` (174 KB) — لا تجميد للواجهة.
4. **الاعتماد على WASM**: ImageMagick (16.2 MB `.wasm`) + Potrace — أي أن تحويل الصور إلى خطوط قابل للرسم يتم بالكامل محليًا وبلا سيرفر.
5. **التتبّع مكثّف**: 34 ملفًا في `sagas/mixpanel/saga/` لتتبّع كل شيء تقريبًا (وهذا باعث إزعاج/مخاطرة خصوصية يقدر المنافس يستغلّها: «بلا تتبّع» كوعد تسويقي).
6. **الحدود مدفوعة**: `isFreeUser` / `isPausedUser` / `LimitsPanel` / علامة مائية — نموذج تسعير صارم يمكن للمنافس تجاوزه بالمجانية الكاملة.
7. **source maps مضمَّنة** = تسريب بنيوي (severity عالية): أي منافس يستطيع استرجاع الكود كاملًا. المنافس يجب أن يُعطّل `build.sourcemap` في الإنتاج.
